# Agents

## Definizione

Un Agent interpreta la Knowledge.

Non acquisisce dati.

Non salva dati.

Produce Evidence.

---

## Pipeline

Knowledge

↓

Reasoning

↓

Evidence

---

## Esempio

ATP_RANK

OUTPUT

## Regola

Ogni Agent deve avere una sola responsabilità.

Ogni Agent deve essere testabile in modo indipendente.
